# Roadmap — Tabletop platform

## Design
- [ ] Retro pixel/8-bit design system (cream + yellow, JetBrains Mono, pixel borders) for platform shell
- [ ] Classic Catan theme (hex tiles, resource colours) inside the game screens

## Phase 1 — platform shell
- [ ] Landing page: "One shared board. Everyone plays from their own phone." + Host / Join
- [ ] Game catalogue: CATAN available, coming-soon placeholders
- [ ] Game selection page (host flow)
- [ ] Create room: room id, 4-digit join code, QR
- [ ] Join page: code entry + QR deep link, nickname
- [ ] Lobby: live player list on shared screen, ready states

## Phase 2 — backend
- [ ] Lovable Cloud: rooms, players tables + realtime sync

## Phase 3 — Catan game
- [ ] Shared screen board view (public state)
- [ ] Phone dashboard (private resources, actions)
